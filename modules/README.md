## How to use a module

1. Answer the opening recall prompts before reading.
2. Read `must-know.md` and reproduce its decision table from memory.
3. Complete the guided lab.
4. Validate every observable result.
5. Complete the challenge without copying the guided procedure.
6. Analyze the architecture scenario and reject each distractor explicitly.
7. Clean up all resources.
8. Take the quiz closed-book.
9. Add misses to your error log.

Do not advance when you can repeat facts but cannot select or defend an architecture.
