# SAP-C02 Exam Format and Strategy

## Confirmed format

| Fact | Current value |
| --- | --- |
| Total questions | 75 |
| Scored questions | 65 |
| Unscored questions | 10, not identified |
| Appointment time | 180 minutes |
| Response types | Multiple choice and multiple response |
| Scaled score range | 100-1,000 |
| Minimum passing score | 750 |
| Guessing | No penalty; unanswered responses are incorrect |

The 75 total follows directly from the official guide's 65 scored plus 10
unscored questions. Treat every question as scored because AWS does not identify
the unscored questions. In multiple-response items, all correct responses must
be selected to receive credit.

## Three-pass plan

Use the plan in fresh practice sets before relying on it.

1. **Pass 1, 0-105 minutes:** target 75-90 seconds for a clear item and no more
   than 150 seconds for a difficult one. Answer, flag uncertainty, and move.
2. **Pass 2, 105-155 minutes:** revisit flagged items. Rebuild only the
   requirements that distinguish the final two options.
3. **Pass 3, 155-180 minutes:** verify multiple-response counts, eliminate blank
   answers, and review only responses with a concrete reason. Do not replace a
   supported answer because of vague anxiety.

At 45, 90, and 135 minutes, compare completed question count with 19, 38, and 57.
If behind by more than three, stop rereading background details and apply
constraint-first elimination.

## Per-question routine

1. Read the final sentence first to identify the requested outcome and response
   count.
2. Extract hard constraints: time, data loss, compliance, protocol, scale,
   ownership, migration interruption, and cost priority.
3. Identify the current state and the required end state.
4. Rank words: `must`, numeric targets, and regulatory constraints outrank
   `prefer`, convenience, and familiar technology.
5. Eliminate any option that violates one hard constraint.
6. Among valid options, choose the one that meets the stated priority with the
   least unnecessary operational burden.
7. Answer every item. There is no guessing penalty.

## Scoring discipline

The exam uses compensatory scoring: passing is based on the total scaled score,
not a required pass in each domain. Preparation should not exploit that fact.
Weakness in networking, identity, or migration often crosses several domains.
Track speed, confidence, and explanation quality in addition to raw percentage.
