# SAA-C03 Integration

## Purpose

Integrate prior labs into exam decisions. This module uses original scenarios only; it does not reproduce or reconstruct proprietary exam questions.

## Official exam facts

AWS currently specifies:

- 65 total questions: 50 scored and 15 unscored.
- 130 minutes.
- Multiple-choice and multiple-response questions.
- A scaled score range of 100-1,000 and a minimum passing score of 720.
- Unanswered questions are incorrect, and there is no penalty for guessing.
- Scored-content weights: Secure 30%, Resilient 26%, High-Performing 24%, Cost-Optimized 20%.

The 15 unscored questions are not identified. The exam uses compensatory scoring, so readiness must be strong overall without ignoring a domain.

## Workflow

1. Review each domain guide.
2. Complete the [service decision drills](service-decision-drills.md).
3. Apply the [distractor method](distractor-analysis.md).
4. Take [mixed set 1](mixed-scenarios-01.md), then review its [answers](mixed-scenarios-01-answers.md).
5. Remediate errors before taking [mixed set 2](mixed-scenarios-02.md), then review its [answers](mixed-scenarios-02-answers.md).
6. Use the [timed-practice protocol](timed-practice.md).
7. Apply the [remediation loop](remediation.md).
8. Record results in the [SAA scorecard](../../assessments/saa-scorecard.md) and test the [readiness gates](../../assessments/saa-readiness.md).
9. Defend both associate capstones:
   - [Three-tier application](../../capstones/01-three-tier/README.md)
   - [Event-driven order processing](../../capstones/02-event-driven/README.md)
