## Evidence standard

Every capstone requires:

- Requirements traceability
- Architecture diagram with trust and failure boundaries
- Architecture decision records
- Security and threat analysis
- RTO/RPO or availability reasoning
- Performance and scaling reasoning
- Cost model and cost controls
- Operations, observability, and incident plan
- Failure or game-day evidence
- Cleanup proof for anything deployed
- A defense explaining why plausible alternatives were rejected
