# Current Exam Blueprints

Verify the official exam guide again before booking. AWS can update guides and in-scope services.

## SAA-C03

AWS Certified Solutions Architect - Associate validates design against the AWS Well-Architected Framework.

| Domain | Weight |
| --- | ---: |
| Design Secure Architectures | 30% |
| Design Resilient Architectures | 26% |
| Design High-Performing Architectures | 24% |
| Design Cost-Optimized Architectures | 20% |

Current official exam-guide facts:

- 65 total questions
- 50 scored questions
- 15 unscored questions
- Multiple-choice and multiple-response
- 130 minutes
- Minimum scaled score: 720 on a 100-1,000 scale
- Unanswered questions are incorrect; there is no penalty for guessing
- AWS describes the target candidate as having at least one year of hands-on experience designing cloud solutions with AWS

[Official SAA-C03 guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)

## SAP-C02

AWS Certified Solutions Architect - Professional validates advanced architecture across applications, projects, and complex organizations.

| Domain | Weight |
| --- | ---: |
| Design Solutions for Organizational Complexity | 26% |
| Design for New Solutions | 29% |
| Continuous Improvement for Existing Solutions | 25% |
| Accelerate Workload Migration and Modernization | 20% |

Current official exam-guide facts:

- 75 total questions
- 65 scored questions
- 10 unscored questions
- Multiple-choice and multiple-response
- 180 minutes
- Minimum scaled score: 750 on a 100-1,000 scale
- Unanswered questions are incorrect; there is no penalty for guessing
- AWS describes the target candidate as having two or more years of experience designing and implementing AWS solutions

The current guide also identifies emerging, unscored topics around security and responsible AI controls.

[Official SAP-C02 guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-professional-02/solutions-architect-professional-02.html)

## What the exams do not test directly

The current SAA-C03 and SAP-C02 exams use selected-response questions rather than live console labs. Hands-on practice remains essential because it builds the mental models needed to evaluate scenario tradeoffs.
