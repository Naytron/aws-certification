# Recommended Learning Resources

Use official material as the source of truth and this repository as the practice sequence.

## Free starting points

- [AWS Skill Builder](https://skillbuilder.aws/) - free digital courses and learning plans
- [AWS Certification preparation](https://aws.amazon.com/certification/certification-prep/) - official exam-prep resources
- [AWS Documentation](https://docs.aws.amazon.com/) - service behavior and quotas
- [AWS Workshops](https://workshops.aws/) - hands-on workshop catalog; check account and cost requirements before running
- [AWS Architecture Center](https://aws.amazon.com/architecture/) - reference architectures and guidance
- [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected/) - pillar guidance and review questions
- [AWS re:Post](https://repost.aws/) - community and official technical discussions

## Optional paid sandbox supplement

An AWS Skill Builder Individual subscription can provide Builder Labs and additional immersive practice. Consider it when:

- A professional topic is blocked in the Free plan.
- A lab would create persistent or expensive services.
- You want open-ended Jam challenges after completing guided labs.

Verify current subscription features and pricing at [AWS Skill Builder subscriptions](https://skillbuilder.aws/subscriptions). The core course does not require a subscription.

## Resource-selection rule

Prefer, in order:

1. Current official exam guide
2. Current service documentation
3. AWS Well-Architected and Prescriptive Guidance
4. Official workshops and Skill Builder
5. Third-party explanations for alternate phrasing, never as the final authority
