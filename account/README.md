# Learning Account Setup

Complete these documents in order:

1. [Create the Free-plan account](free-plan-signup.md)
2. [Apply the security baseline](security-baseline.md)
3. [Configure budgets and alerts](budgets-and-alerts.md)
4. [Practice cleanup and understand account closure](cleanup-and-account-closure.md)

Do not start a service lab until all four steps are complete.

## Phase 0 evidence

Record only non-sensitive evidence:

- Root MFA is enabled
- No root access keys exist
- Daily work uses a non-root identity
- Free Tier and budget notifications are configured
- A home Region is selected
- Required resource tags are documented
- The test deployment was removed
- Resource inventory returned to the expected baseline

Never capture passwords, access keys, session tokens, full account IDs, payment information, or private endpoints in this repository.
